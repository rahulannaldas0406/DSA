## Node

class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

A Node contains:
- data
- reference to next Node

## Connecting Nodes

node1.next = node2

Example:

10 → 20 → 30 → None

## Head

head points to the first node.

head → 10 → 20 → 30 → None

## Traversal

current = head

while current:
    process(current.data)
    current = current.next

head = starting point
current = traversal pointer
next = reference to the next node
